# Kalkulator-Limit
Kalkulator Limit adalah kalkulator limit web interaktif berbasis Python, SymPy, dan Streamlit. Mendukung kalkulasi simbolik eksak, otomatisasi Aturan L'Hôpital untuk bentuk 0/0, uji kontinuitas, ekspansi deret Taylor, serta visualisasi grafik Plotly real-time. Cocok untuk analisis kalkulus tingkat lanjut secara praktis dan presisi.
